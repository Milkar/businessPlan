# BP Skill 评估：现有 skill 盘点 + v3 投资人视角差距

## 一、可配合使用的其他 skill / 插件

| 名称 | 类型 / 状态 | 适合做什么 | 评价 |
|---|---|---|---|
| **cofounders**（社区） | 插件，未安装 | `cofounderpitch-prep` 路演准备、`investor-agent` 投资人视角、`cofoundermarket-intel` 市场情报、`cofounderroi-calculator` ROI 测算 | **最贴合创业融资**。建议用来：模拟投资人追问、补 ROI 框架。社区插件，结论需人工核对 |
| **pitch-agent**（Anthropic 官方） | 插件，未安装 | `pitch-deck`、`3-statement-model`、`dcf-model`、`comps-analysis`、`xlsx-author`、`pptx-author` | `pitch-deck` 是**投行模板填充**，不是创业 BP；但 `3-statement-model` + `xlsx-author` 适合搭 3.5 节财务模型，`comps-analysis` 适合整理可比公司估值 |
| **strategy-frameworks**（社区） | 插件，未安装 | `pyramid-principle`、`bmc`、`lean-startup`、`porter` 等 47 个框架 | 用 `pyramid-principle` 检查「结论先行」，用 `bmc` 自查商业模式完整性 |
| **Brouky**（社区） | 插件，未安装 | VC 查找、deck 分析、投资人数据 | 后期找投资人、按机构偏好调整 BP 时有用；需注册其服务 |
| `deep-research` | 内置 | 多来源调研并写成报告 | 补 TAM/SAM/SOM、类器官 / 虚拟细胞市场、可比融资，带出处 |
| `xlsx` | 内置 | 电子表格 | 收入预测、单位经济、资金消耗表 |
| `pptx` / 幻灯片 Artifact | 内置 | 路演 PPT | 最终从 Markdown 渲染为 12–18 页路演版 |
| `interview-business-plan` | 你已有（claude-config） | 面试用的入职一年计划 PPT | 不适用于创业 BP；但「数据来源必须可点开」「行动项要具体可检查」两条原则已吸收进 `startup-bp` |

**推荐组合**：`startup-bp`（主流程，本仓库） + `deep-research`（市场数据） + `xlsx` / pitch-agent `3-statement-model`（财务） + cofounders `pitch-prep`（投资人模拟追问） + `pptx`（路演版）。

## 二、v3 对照投资人清单的差距（按尽调追问的可能性排序）

| 优先级 | 缺口 | 现状 | 建议 |
|---|---|---|---|
| 🔴 高 | **人类遗传资源 / 伦理 / 数据出境合规**（B1–B3） | 全文未提及；项目涉及患者样本、纵向组学、与 DKFZ 等海外机构的合作 | 新增「合规与风险」节：遗传办审批 / 备案路径、伦理批件、数据存储与出境方案 |
| 🔴 高 | **估值、出让比例、财务预测**（A11–A12） | 3.5 全部【待补充】 | 先用 xlsx 搭四级收入模式的测算模型，由团队填关键假设 |
| 🔴 高 | **市场规模 TAM/SAM/SOM**（A2） | 只有「10+ 年 / $20 亿+」，且无出处 | 用 deep-research 做自下而上测算：目标瘤种病例数 × 单例价格；药企转化研究外包预算 |
| 🟠 中 | **已有进展与牵引力**（A4–A5） | 发表成果有；样本量、已建 PDO 数、合作医院、意向客户未写 | 单列「我们已经有什么」：样本库规模、建模成功率、合作中心、LOI |
| 🟠 中 | **知识产权与原单位关系**（B6、B8） | 未提及 | 写专利计划、与 DKFZ / 海德堡大学的 IP 归属；核心科学家是否全职 |
| 🟠 中 | **风险章节**（A14） | 无独立章节（克制表述散落各处） | 集中列 5–6 项：建模失败率、前瞻验证不达标、样本入组慢、监管、人才、竞争 |
| 🟠 中 | **监管路径**（B4） | 只到「临床决策支持需机构采用与支付支持」 | 说明研究服务阶段无需注册证；临床阶段走 LDT / NMPA 三类软件的时间表 |
| 🟡 低 | 资金占比与里程碑一一对应（A10） | 占比合计 100%、金额合计 5000 万，已核对一致；但每项资金未对应具体里程碑 | 资金表加一列「对应里程碑」 |
| 🟡 低 | 路演版篇幅（C） | Markdown 详细版约 30 节 | 另出 12–18 页路演版，技术细节进附录 |

## 三、建议的下一步
1. 先确认两条待定建议（飞轮合并、飞轮章节标题），出 v4。
2. v4 同时补「合规与风险」节框架和「已有进展」节框架（只搭框架，不编数字）。
3. 团队提供财务假设后，用 xlsx 建模型，回填 3.5。
4. 用 cofounders `pitch-prep` 做一轮模拟投资人问答，把高频追问补进 BP 或 Q&A 附录。
5. 定稿后渲染为路演 PPT。
