**我们的技术优势，三种说法（后文反复出现）：**

- **一句话**：别人用「更大的公开数据」训练模型，我们用「同一位患者的两条时间轨迹」校准模型。
- **一个公式**：患者 T0 → T1（体内真实演化） ⇄ 类器官 T0 → T1（体外可控实验） ⇒ 虚拟类器官。
- **一个比喻**：就像飞行员先在模拟器里把这趟航班飞一遍，我们先在虚拟类器官里把这位患者的治疗走一遍，再决定真实用药。

# 第一步　为什么要做：市场需求与现有缺口

## 1.1 行业代价：药物研发的「试错」已不可承受

| 指标 | 数据 |
|---|---|
| 失败暴露阶段 | **临床后期**——代价最高的阶段 |
| 创新药从发现到上市平均耗时 | **10+ 年** |
| 平均研发花费 | **$20 亿+**（且仍在上升） |

**为什么失败在后期才暴露？** 早期模型预测不了患者之间的差异，更追不上肿瘤随时间的演化：细胞模型上有效 → 动物模型上有效 → 患者身上无效甚至有害。

**根本矛盾**：候选药物太多、患者差异太大、生命状态随时间持续变化，真实实验永远做不过来；耐药与复发要等到患者治疗失败后才被看见。

*来源：AIVC 商业故事 BP §2.1；行业公开数据。*【待补充：10+ 年 / $20 亿+ 的具体出处与年份】

## 1.2 临床缺口：治疗选择缺少及时、患者特异性的功能证据

| # | 缺口 | 说明 |
|---|---|---|
| 1 | **分子图谱是静态快照** | 基因组能提示脆弱性，但疗效还取决于细胞状态、生态、治疗史与可塑性；单次检测只代表采样那一刻 |
| 2 | **反馈滞后** | 影像与临床结局只在患者已经接受治疗之后才说明发生了什么 |
| 3 | **工具割裂** | 类器官药筛停在「敏感 / 不敏感」，很少转化为经过校准的患者纵向预测 |

**外部证据**：Peng et al., *Cell Stem Cell* 2025——患者来源脑肿瘤类器官（IPTO）高保真保留肿瘤生态系统，并在前瞻性临床研究中预测患者治疗响应（PFS / OS，p = 0.034 / 0.033）。
**同时要诚实**：已有前瞻研究（如结直肠癌）表明，类器官的预测表现取决于治疗类别与实施情境——所以需要的是「校准 + 前瞻验证」，而不只是药筛。

## 1.3 为什么是现在：四项条件同步成熟

| 条件 | 现状 |
|---|---|
| 类器官技术 | IPTO 能高保真保留肿瘤生态系统，个体差异与微环境同时在线，可纵向追踪 |
| 成像与测量 | 长时程活细胞成像、高内涵成像、单细胞 / 空间组学，把细胞状态变成可计算的多模态数据 |
| 数据与算力 | 多模态数据基础设施成熟，大规模训练成本显著下降 |
| AI 方法 | 自监督预训练 + 扰动建模，让 AI 能学习「干预后进入什么新状态」 |

## 1.4 核心缺口：缺的不是算法，而是「对的数据」

AI 已经能学习细胞状态，全球也在大规模补充细胞扰动数据。但要回答「**这位患者、在这次治疗之后，会变成什么样**」，需要的是另一种数据，而它在公开数据中很少见：

| 要回答这个问题，数据必须同时具备 | 今天的公开数据 |
|---|---|
| **来自同一位患者**（而不是细胞系或混合样本） | 多为细胞系或跨患者汇总 |
| **跨越时间**（治疗前 → 治疗后 / 复发） | 多为单一时间点的快照 |
| **带有干预**（知道做了什么、剂量多少） | 部分具备，且多不与患者关联 |
| **有真实结局打分**（预测对不对，由临床结局判定） | 几乎没有 |

*右列为对公开数据集现状的定性概括，依据科学家文档「行业缺少患者配对 × 纵向 × 扰动 × 结局评分数据」的判断。*【待核：请科学家确认表述】

**谁能拿到同时满足这四个条件的数据，谁就能把「事后发现」变成「事前预测」。**

> **第一步小结**：治疗决策需要「事前预测」，而行业缺的是能支撑事前预测的「真实配对纵向数据」。

# 第二步　为什么我们能做成：技术优势与护城河

## 2.1 核心思想：两条时间轨迹，互相校准

第一步的结论是：行业缺的是「同一位患者、跨越时间、带干预、有结局打分」的数据。我们的答案不是去公开渠道找，而是**自己造**——让同一位患者的两条时间轨迹互相校准。

> 同一位患者的真实肿瘤在体内随时间演化（进展或复发）；同时用体外患者类器官（PDO）作为**可控的「平行实验系统」**。两条时间轨迹不断校准彼此，最终得到能预测这位患者下一状态的虚拟类器官。

```
                     患者初始肿瘤 T0
                  ┌────────┴────────┐
          患者样本库                PDO T0 ──→ 体外培养 / 药物 / 压力 / 营养
                  │                       │
            患者复发 T1                 PDO T1
                  └────────┬────────┘
                     多组学 / 表型
                           ↓
              longitudinal disease trajectory
                           ↓
                  Virtual Organoid（虚拟类器官）
                  ┌────────┴────────┐
             模拟疾病演化        模拟治疗响应
                  └────────┬────────┘
                    预测患者下一状态
```

**为什么这是优势**：体内轨迹「真实但不可重复」（不能在患者身上批量试药）；体外轨迹「可控、可重复」但可能有培养偏差。两者互相校准，各补对方的短板——单做动物模型、单做类器官药筛、单用公开数据训练，都做不到。

## 2.2 技术如何实现：先「认识细胞」，再「预测干预」

**第一步 · 自监督预训练——解决「数据不够」**
海量无标注数据（细胞图像、组学）→ 模型做信息补全（预测被遮住的基因表达、还原缺失图像区块）→ 学会「细胞状态长什么样」。

**第二步 · 状态转移学习——解决「因果预测」**
多组学（RNA / 蛋白 / 代谢 / 形态 / 功能表型）经 Encoder 压缩为潜状态 **Z(t)**，学习 **Z(t+1) = F(Z(t), 干预)**。Z(t) 的不同维度可对应增殖、干性、代谢、应激、免疫互作、DNA 损伤、脂质重塑、治疗抵抗。

模型最终回答的是这一个问题：

> **「什么样的初始状态，在什么干预下，会进入什么新状态？」**
> PDO(T0) → PDO(T1) → PDO(T2)……

**两步缺一不可**：只有第一步，模型只会描述、不会预测；只有第二步，模型缺少泛化能力。

**读出的七层证据**：基因组（WES/WGS）· 转录组（scRNA-seq / bulk RNA）· 蛋白组 · 代谢组（葡萄糖 / 脂质代谢）· 影像形态 · 功能表型（增殖 / 凋亡 / 耐药）· 空间转录组（条件允许时）。

**虚拟药物筛选 / 虚拟治疗测试**：在 PDO 上做治疗与药物扰动实验，模型学到扰动规律后，就能在虚拟空间里批量测试，再挑出少量最值得真实验证的候选。

## 2.3 数据飞轮：为什么模型越用越准

前两节讲的是模型「怎么学」；这一节讲它「为什么会越学越好」。答案是：**每一位患者走完一圈闭环，模型就被真实结局校准一次**——这就是我们的数据飞轮。

**飞轮的一圈 = 一个病例的七步闭环**（患者既是起点，也是终点）：

```
   01 患者基线（T0 组织与临床情境）
          ↓
   02 建立类器官（确认检测质量与培养偏差）
          ↓
   03 扰动与读出（多组学纵向测量治疗响应与耐药）
          ↓
   04 锁定预测 ←── 在结局发生之前完成并锁定
          ↓
   05 观察结局（T1：真实的治疗响应 / 复发 / 进展）
          ↓
   06 预测评分（盲态评估准确度与校准度）
          ↓
   07 更新系统（改进模型、检测与适用范围）──→ 回到 01，下一位患者
```

**飞轮为什么能越转越快**——每转一圈，同时加厚三层数据中最稀缺的那一层：

| 数据层 | 特点 | 我们的位置 |
|---|---|---|
| 自监督数据 | 海量、低成本，学「细胞长什么样」 | 公开数据 + 自有图像，用于预训练 |
| 监督数据 | 学映射，但难以区分因果 | 辅助 |
| **扰动配对数据** | **稀缺、昂贵，能学到「干预 → 响应」的因果规律** | **每个病例都在产出，资源集中于此** |

**飞轮的三条运行原则**（也是它可信的原因）：
1. **类器官是平行实验载体**：既保留患者肿瘤特异性，又能在体外安全、规模化地测试干预。
2. **不用模型生成的数据训练模型**：训练素材必须来自真实实验与临床随访；**先锁定预测、后观察结局**，保证回灌的数据可信。
3. **只有能改善预测、校准或质量控制的检测才进入标准流程**：飞轮越转越精，而不是越转越重。

> **一句话**：别人的模型靠「堆数据」变大，我们的模型靠「被真实结局反复打分」变准。

## 2.4 护城河：飞轮每转一圈，四道壁垒同时加深

| # | 壁垒 | 它是什么 | 为什么难复制 | 飞轮如何加深它 |
|---|---|---|---|---|
| ① | **纵向配对数据** | 在病例层连接基线组织、类器官实验、治疗暴露与患者结局 | 必须有患者随访与类器官体系，公开渠道拿不到 | 每个病例新增一条配对轨迹 |
| ② | **扰动响应图谱** | 把「干预 → 状态转变 → 耐药机制」连成结构化证据；统一 SOP、多剂量、多时间点 | 真实实验产生，成本高、周期长 | 每次扰动实验扩充图谱 |
| ③ | **培养偏差校正** | 量化体外培养带来的信息丢失、富集与系统偏差，把类器官结果校准还原到患者体内 | 必须先有①的配对数据才能训练 | 配对越多，偏差模型越准 |
| ④ | **嵌入临床流程** | 合格检测、数据标准、中心集成、报告与**前瞻性验证** | 需要医院与随访渠道，靠时间与信任积累 | 每次锁定—评分都积累验证记录 |

①②③④不是并列的四件事，而是**同一个飞轮带动的一个整体**：竞争对手可以复制算法，但要复制这四道壁垒，只能从第一个病例开始重新转飞轮。

## 2.5 如何证明：一个核心问题，三级验证

**核心科学问题**

> **PDO T0 → PDO T1 的变化，能否预测 Patient T0 → Patient T1 的真实变化？**

验证方式示意（以放疗 RT 为例）：

| 特征 | 患者 T0 → T1（真实复发） | PDO T0 → T1（体外同样处理） | 虚拟类器官预测 |
|---|---|---|---|
| 干性 stemness | ↑ | ↑ | ↑ |
| 脂质代谢 lipid metabolism | ↑ | ↑ | ↑ |
| 氧化应激 oxidative stress | ↑ | ↑ | ↑ |
| 增殖 proliferation | ↓ | ↓ | ↓ |
| 治疗抵抗 resistance | ↑ | ↑ | ↑ |

> 注：上表是科学家方案中的**示意性假设**，用来说明验证方式，**不是已发表的结果**。【待核：投资人版本是否保留】

**三级验证，逐级设闸**——每一级只回答一个问题，过闸才进入下一级：

| 层级 | 只回答一个问题 | 通过标准（阶段闸门） |
|---|---|---|
| **Level 1 · Digital Organoid** | PDO 能不能**复制患者肿瘤的状态**？ | 重复性、周转时间、失败率、培养偏差模型达到阈值 |
| **Level 2 · Longitudinal Digital Twin** | PDO 能不能**复制患者疾病的演化**？ | 配对 T0→T1 轨迹的一致性【待补充具体指标】 |
| **Level 3 · Predictive Virtual Organoid** | 虚拟 PDO 能不能**预测患者未来状态与治疗反应**？ | 外部前瞻性准确度、校准度、及时性，以及相对临床 / 影像 / 分子基线的**增量价值** |

最终闭环：`Patient → PDO → Longitudinal data → AI model → Virtual Organoid → Prediction → Patient → Validation → Model update`——也就是 2.3 的飞轮，在验证层面的样子。

Level 3 之后，还要证明决策价值（临床效用、监管路径、支付依据），才进入「**临床肿瘤数字孪生**」。我们**只在系统达到持续更新、患者特异性决策的阶段才使用「数字孪生」一词**——这是对科学的克制，也是对投资人的诚实。

## 2.8 竞争格局：赛道已被资本验证，差异在数据性质与验证闭环

「虚拟细胞 / AI4S」已经成为全球热点：Arc Institute 发布 STATE 虚拟细胞模型，CZI 搭建虚拟细胞平台，单细胞基础模型密集出现，国内也有多家公司拿到大额融资。**赛道被资本验证，说明方向对；但他们补的是「扰动数据」和「通用模型」，没有补 1.4 说的那种患者配对纵向数据**——这正是我们和他们的分界线。

## 2.9 技术优势速记卡（投资人带得走的版本）

| 角度 | 他们 | 我们 |
|---|---|---|
| **数据** | 要「更多细胞」 | 要「同一个人的两条时间线」 |
| **方法** | 模型直接拼接数据 | 模型被**体内轨迹**持续校准 |
| **可信度** | 模型自己给自己打分 | 先锁定预测、再用真实结局盲态评分 |
| **偏差** | 忽略或无法量化培养偏差 | 用自己的配对数据**量化并校正** |

# 第三步　做成之后：价值与投资回报

## 3.1 社会价值

- **让耐药与复发「提前被看见」**：从「治疗失败后才发现」变为「事前预测演化趋势」（例如模型提前提示干性↑、脂质代谢↑、治疗抵抗↑）。
- **让治疗决策有患者特异性证据**：在换药等决策窗口输出针对这位患者的预测，并随临床结局持续校准——为精准肿瘤诊疗增加一层**功能证据**。
- **缩短试错、降低失败代价**：在临床结局显现前先在虚拟空间完成药效推演，减少投向最终无效候选药物的资源。
- **留下可复用的科学资产**：患者–PDO 纵向配对数据与可验证的因果生物模型，可向跨疾病、多尺度延伸。

【待补充】可量化指标：目标瘤种年新发 / 复发患者数、可减少的无效治疗比例、可缩短的研发周期。

## 3.2 商业价值与盈利模式：证据到哪一步，收入走到哪一步

| 阶段 | 模式 | 内容 | 收费方式 |
|---|---|---|---|
| **近期** | 联合开发 / 研究项目 | 围绕明确研发问题交付候选排序、机制解释、验证结果；客户买的是研发答案，不是单次类器官培养 | 研究预算 + 里程碑 |
| **中期** | 按病例预测服务 + 队列共建 | 标准化类器官分析与患者预测报告；与药企、医院共建队列与联合验证 | 首付款 + 里程碑付款；按病例收费 |
| **规模化** | 平台许可 + 数据服务 | 向合格伙伴提供分析、数据访问与流程集成 | 许可费 + 使用费 |
| **临床阶段** | 决策支持 | 把经验证的治疗比较预测嵌入诊疗路径 | 机构采购与支付方支持 |

这个顺序让**资源投入与证据相匹配**：先做研究合作，再标准化流程，完成前瞻性验证后才推进临床主张。

**三类客户，各自买到什么**

| 客户 | 价值 | 初始合作形态 |
|---|---|---|
| 制药与生物技术企业（含 CRO、CGT） | 在患者关联的功能模型中识别响应特征、耐药程序与合理联合方案；加强试验设计、生物标志物与机制证据 | 联合开发研究 |
| 肿瘤中心 · 临床研究者 | 在标准诊疗旁路获得及时预测，评估相对现有信息的增量价值 | 前瞻性临床研究 |
| 类器官平台与实验室 | 为成熟检测增加标准化解读、纵向校准与面向临床的报告，无需重建全栈 | 平台模块集成 |

**为什么客户买我们，而不是自己建？** 配对队列、培养偏差校正、跨项目模型复用都需要病例和时间，自建门槛高、周期长。
**为什么我们的毛利会越来越高？** 项目交付与 2.3 的飞轮是同一条生产链：每个付费项目同时沉淀新的配对数据，下一个项目的边际交付成本更低——**服务收入与模型资产同步增长**。【待补充：单项目成本与毛利率的测算】

# 结语：请记住这三句话

1. **为什么做**：耐药与复发总是后知后觉，而行业缺的是能做事前预测的真实配对纵向数据。
2. **为什么能成**：同一位患者的**两条时间轨迹互相校准**，每个病例都用真实结局给模型打一次分——这套配对数据与验证链路，别人无法靠算法追上。
3. **做成值多少**：从研究合作走到临床决策支持，**证据走到哪里，收入就走到哪里**。

**知微 Chronoid｜让每一次治疗，先在患者自己的类器官上预演——让复发与耐药，在发生之前被看见。**
