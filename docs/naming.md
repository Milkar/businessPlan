# 项目名称与 Slogan 方案

## 命名原则
1. **有力**：2 个汉字 + 1 个英文词，好读、好记、可注册；不用「AI」「智能」「科技」这类泛词。
2. **有意**：名字本身就指向核心机制或使命——「时间轨迹」「提前看见」「先预演再用药」。
3. **克制**：不用「孪生 / Twin」（BP 承诺只在 Level 3 之后用「数字孪生」），不用「治愈 / 精准」这类过度承诺的词。
4. **与 AIVC 分层**：名称是公司 / 项目品牌，AIVC 虚拟类器官是产品 / 平台。
5. **slogan 是使命句**：一句话讲清「为谁、用什么、做到什么」，≤ 20 字。

## 推荐方案：知微 Chronoid

| 项目 | 内容 |
|---|---|
| 中文名 | **知微**：「知微见著」，出自《周易·系辞下》「君子知微知彰」。意思是从细微的早期信号，看见将要发生的结局 |
| 英文名 | **Chronoid** = *Chrono*（时间）+ *-oid*（Organoid，类器官）：纵向时间轨迹上的类器官，一个词讲清技术核心 |
| Slogan（使命） | **让每一次治疗，先在患者自己的类器官上预演** |
| 价值主张（保留） | 让复发与耐药，在发生之前被看见 |
| 英文 slogan | *Rehearse every treatment on the patient's own organoids — first.* |

**为什么推荐**
- 中文名有文化分量，又和 BP 的价值主张「在发生之前被看见」完全同义，封面上下文互相印证。
- 英文名直接对应最强的壁垒「纵向配对数据」，投资人问「为什么叫这个名字」时，正好可以讲双轨迹校准。
- slogan 用的是摘要里「飞行员模拟器」的比喻（先在模拟器里飞一遍），全文叙事一致。

## 备选方案

| # | 名称 | 含义 | Slogan | 取向 |
|---|---|---|---|---|
| B | **先见 Foretrack** | 先见之明；*Fore*（提前）+ *Track*（轨迹）：提前看清疾病轨迹 | 看清肿瘤的下一步，再决定这一步 | 最直白，强调「预测」 |
| C | **知时 Kairoid** | *Kairos*（希腊语「恰当的时机」）+ *-oid*：在决策窗口给出证据 | 在对的时刻，为每位患者选对治疗 | 强调临床决策窗口，偏临床 / 医生视角 |
| D | **双轨 Bitrace** | 双轨迹校准：患者体内 × 类器官体外 | 两条时间线，一个更早的答案 | 最强调技术壁垒，偏技术型投资人 |

**Slogan 备选**（可与任一名称搭配）
1. 让每一次治疗，先在患者自己的类器官上预演（推荐：使命 + 方法 + 价值都在）
2. 先预演，再用药（最短，适合 logo 下方或路演结尾）
3. 用你自己的肿瘤，预演你的下一次治疗（第二人称，面向患者 / 医生传播）

## 已排除的方向（避免撞名或越界）
- **Prescient**：澳大利亚已有肿瘤药企 Prescient Therapeutics（ASX: PTX）。
- **Prelude**：美国已有肿瘤药企 Prelude Therapeutics。
- **Organova / Organovo**：Organovo 是已上市的 3D 生物打印公司。
- **Twin / 孪生**：与 BP「不夸大数字孪生」的原则冲突。
