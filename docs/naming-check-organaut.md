# 名称评估：Organaut AI（2026-10-09）

## 含义
Organ(oid) + -naut（希腊语「航行者」，同 astronaut、argonaut）＝「在类器官里航行、探索的人」。贴合「用类器官探索患者体内的未来状态」。

## 中文名建议
| 中文名 | 读音 | 含义 | 评价 |
|---|---|---|---|
| **器航**（推荐） | qì háng | 器 = 类器官，航 = -naut 航行；与「启航」近音 | 与英文逐字对应，简短好记；初步检索无同名企业 |
| 灵器 | líng qì | 灵 = 智能（AI），器 = 类器官 | 有「AI + 类器官」双义，但带玄幻色彩，偏不严肃 |
| 器探 | qì tàn | 探索类器官 | 意思直白，音韵较弱 |

公司全称建议：**器航智能（Organaut AI）**；若注册为生物公司可用「器航生物」。
