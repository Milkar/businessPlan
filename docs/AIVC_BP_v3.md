# 第一部分　为什么要做这件事：市场需求与现有缺口

## 1.1 行业需求：药物研发的「试错」已不可承受

| 指标 | 数据 |
|---|---|
| 失败暴露阶段 | **临床后期**——代价最高的阶段 |
| 创新药从发现到上市平均耗时 | **10+ 年** |
| 平均研发花费 | **$20 亿+**（且仍在上升） |

**为什么失败在后期才暴露？** 早期模型预测不了患者之间的差异，更追不上肿瘤随时间的演化：

- 细胞模型：体外有效
- 动物模型：动物有效
- 患者身上：无效甚至有害

**根本矛盾**：候选药物太多、患者差异太大、生命状态随时间持续变化，真实实验永远做不过来；耐药与复发要等到患者治疗失败后才被看见。**试错范式走到尽头，必须换一条路。**

*来源：AIVC 商业故事 BP §2.1；行业公开数据。*【待补充：10+ 年 / $20 亿+ 的具体出处与年份】

## 1.2 临床需求：治疗选择缺少及时、患者特异性的功能证据

治疗决策缺少「对应这名患者、对应病程当下节点」的功能证据。三个缺口：

| # | 缺口 | 说明 |
|---|---|---|
| 1 | **分子图谱不完整（静态证据）** | 基因组能提示脆弱性，但疗效还取决于细胞状态、生态、治疗史与可塑性；单次检测只是采样时点的快照 |
| 2 | **反馈滞后（失败后才知道耐药）** | 影像与临床结局只在患者已经接受治疗之后才说明发生了什么 |
| 3 | **工具割裂（功能检测止于敏感性）** | 类器官药筛很少转化为经过校准的患者纵向预测 |

**外部证据**：Peng et al., *Cell Stem Cell* 2025——患者来源脑肿瘤类器官（IPTO）高保真保留肿瘤生态系统，并在前瞻性临床研究中预测患者治疗响应（PFS / OS，p = 0.034 / 0.033）。
**同时要诚实**：已有前瞻性研究（如结直肠癌）表明，类器官的预测表现取决于治疗类别与实施情境——这正是为什么需要「校准 + 前瞻验证」，而不是只做药筛。

## 1.3 时机：四项技术条件同步成熟

| 条件 | 现状 |
|---|---|
| 类器官技术 | IPTO 能高保真保留肿瘤生态系统，个体差异与微环境同时在线，可纵向追踪演化 |
| 成像与测量 | 长时程活细胞成像、高内涵成像、单细胞 / 空间组学，把细胞状态转化为可计算的多模态数据 |
| 数据与算力 | 多模态数据基础设施成熟，大规模训练成本显著下降 |
| AI 方法 | 自监督预训练 + 扰动建模，使 AI 能学习「干预后进入什么新状态」 |

## 1.4 核心缺口：行业浪潮缺的是「真实的患者纵向配对数据」

全球「虚拟细胞 / AI4S」浪潮已经出现（Arc Institute 的 STATE、CZI 虚拟细胞平台、单细胞基础模型密集出现），并在补足**扰动数据**。但它们的**共同结构性短板**是：

> 缺少 **患者配对 × 纵向 × 扰动 × 结局评分** 的数据——
> 即患者特异性纵向轨迹、类器官平行实验和临床结局闭环。

**这个数据缺口，正是我们的入口。**

> **第一部分小结（一句话）**：治疗决策需要「事前预测」，而行业缺的是能支撑事前预测的「真实配对纵向数据」。——这就是我们做这件事的理由。

# 第二部分　为什么我们能做成：护城河与技术优势

## 2.1 核心思想：两条时间轨迹，互相校准

> 同一个患者的真实肿瘤在体内随时间发生演化（发展或复发），同时用体外患者类器官（PDO）作为一个**可控的「平行实验系统」**，通过**两条时间轨迹不断校准彼此**，实现孪生和虚拟。

```
                     患者初始肿瘤 T0
                  ┌────────┴────────┐
          患者样本库                PDO T0 ──→ 体外培养 / 药物 / 压力 / 营养
                  │                       │
            患者复发 T1                 PDO T1
                  └────────┬────────┘
                     多组学 / 表型
                           ↓
              longitudinal disease trajectory
                           ↓
                  Virtual Organoid（虚拟类器官）
                  ┌────────┴────────┐
             模拟疾病演化        模拟治疗响应
                  └────────┬────────┘
                    预测患者下一状态
```

**为什么这是优势**：体内轨迹是「真实但不可重复」的（不能在患者身上批量试药）；体外轨迹是「可控、可重复」的但可能有培养偏差。两者互相校准，各补对方的短板——这是单做动物模型、单做类器官药筛、单做公开数据训练都做不到的。

## 2.2 我们要回答的核心科学问题（也是最有说服力的验证）

> **PDO T0 → PDO T1 的变化，能否预测 Patient T0 → Patient T1 的真实变化？**

科学家给出的验证示意（以放疗 RT 为例）：

| 特征 | 患者 T0 → T1（真实复发） | PDO T0 → T1（体外同样处理） | 虚拟类器官预测 |
|---|---|---|---|
| 干性 stemness | ↑ | ↑ | ↑ |
| 脂质代谢 lipid metabolism | ↑ | ↑ | ↑ |
| 氧化应激 oxidative stress | ↑ | ↑ | ↑ |
| 增殖 proliferation | ↓ | ↓ | ↓ |
| 治疗抵抗 resistance | ↑ | ↑ | ↑ |

> 注：上表为科学家方案中的**示意性假设**，用于说明验证方式，不是已发表的结果。BP 中不应将其表述为已达成的成绩。

**读出的七层证据**：基因组（WES/WGS）· 转录组（scRNA-seq / bulk RNA）· 蛋白组 · 代谢组（葡萄糖 / 脂质代谢）· 影像形态 · 功能表型（增殖 / 凋亡 / 耐药）· 空间转录组（条件允许时）。

## 2.3 技术如何实现：先「认识细胞」，再「预测干预」

**第一步 · 自监督预训练——解决「数据不够」**
海量无标注数据（细胞图像、组学）→ 模型做信息补全（预测被遮住的基因表达、还原缺失图像区块）→ 学会「细胞状态长什么样」。

**第二步 · 状态转移学习——解决「因果预测」**
多组学（RNA / 蛋白 / 代谢 / 形态 / 功能表型）经 Encoder 压缩为潜状态 **Z(t)**，学习 **Z(t+1) = F(Z(t), 干预)**。Z(t) 的不同维度可对应：增殖、干性、代谢、应激、免疫互作、DNA 损伤、脂质重塑、治疗抵抗。

模型最终学会的，是这一个问题的答案：

> **「什么样的初始状态，在什么干预下，会进入什么新状态？」**
> PDO(T0) → PDO(T1) → PDO(T2)……

**两步缺一不可**：只学第一步，模型只会描述、不会预测；只学第二步，缺失泛化能力。

**虚拟药物筛选 / 虚拟治疗测试**：在 PDO 上做各种治疗与药物扰动实验，模型学到扰动规律后，就能在虚拟空间里批量测试，再挑出少量最值得真实验证的候选。

## 2.4 护城河：四道壁垒，层层叠加

| # | 壁垒 | 它是什么 | 为什么难复制 |
|---|---|---|---|
| ① | **纵向配对数据** | 在病例层连接基线组织、类器官实验、治疗暴露与患者结局 | 必须有患者随访与类器官体系，无法从公开渠道获得 |
| ② | **扰动响应图谱** | 把「干预 → 状态转变 → 耐药机制」连接为结构化证据；统一 SOP、多剂量、多时间点 | 真实实验产生，成本高、周期长 |
| ③ | **培养偏差校正** | 量化体外培养带来的信息丢失、富集与系统偏差，把类器官结果校准还原到患者体内 | 需要「配对数据」才能训练，没有①就做不出③ |
| ④ | **嵌入临床流程** | 合格检测、数据标准、中心集成、报告与**前瞻性验证**（先锁定预测、再盲态评分） | 需要医院与随访渠道，靠时间与信任积累 |

**数据三层价值**：自监督数据（海量、低成本）→ 监督数据（学映射、难区分因果）→ **扰动配对数据（稀缺、昂贵、能学到干预–响应的因果规律）**。我们的资源集中在第三层。

**复利优势**：每增加一条配对患者轨迹，都会**同时**改善模型校准、检测解释、适应症选择与合作伙伴价值。①②③④不是并列的四件事，而是**互相加固**的一个整体。

**核心差异（再说一遍）**：我们不是复用公开单细胞数据集重复训练模型；我们是持续产出「患者–PDO 纵向配对、扰动响应数据、经临床评分的样本」。模型的学习目标由「识别静态细胞状态」升级为「推演干预之后生物系统随时间演变的趋势」。

## 2.5 闭环运行：先评分，再更新

七步闭环（患者既是起点，也是终点）：

| 步骤 | 内容 |
|---|---|
| 01 患者基线 | 采集组织与临床情境（T0） |
| 02 建立类器官 | 确认检测质量与培养偏差 |
| 03 扰动与读出 | 测量治疗响应与耐药（多组学纵向） |
| 04 **锁定预测** | **在结局发生前**完成并锁定预测 |
| 05 观察结局 | 记录治疗与患者真实响应（T1：复发 / 进展） |
| 06 **预测评分** | 盲态评估准确度与校准度 |
| 07 更新系统 | 改进模型、检测与适用范围，进入下一轮 |

**三条原则**
1. 类器官是**平行实验载体**：既保留患者肿瘤特异性，又能在体外安全、规模化地测试干预。
2. **不可仅凭模型生成的数据训练模型**：训练素材必须来自真实实验与临床随访；先锁定、后观察，保证回灌数据可信。
3. **只有能改善预测、校准或质量控制的检测才进入标准流程**。

**飞轮的三层收益**：对客户——每轮交付研发答案；对公司——每轮沉淀标准化纵向数据、收窄预测误差；对平台——项目越多、数据越厚、模型越准，**这就是护城河的来源**。

## 2.6 我们如何证明：三级验证，逐级设闸

科学家把项目拆成三个层级，每一级只回答一个问题：

| 层级 | 只回答一个问题 | 通过标准（阶段闸门） |
|---|---|---|
| **Level 1 · Digital Organoid** | PDO 能不能**复制患者肿瘤的状态**？ | 重复性、周转时间、失败率、培养偏差模型达到阈值 |
| **Level 2 · Longitudinal Digital Twin** | PDO 能不能**复制患者疾病的演化**？ | 配对 T0→T1 轨迹的一致性【待补充具体指标】 |
| **Level 3 · Predictive Virtual Organoid** | 虚拟 PDO 能不能**预测患者未来状态与治疗反应**？ | 外部前瞻性准确度、校准度、及时性、相对临床 / 影像 / 分子基线的**增量价值** |

最终目标是一个完整闭环：
`Patient → PDO → Longitudinal data → AI model → Virtual Organoid → Prediction → Patient → Validation → Model update`

长期（Level 3 之后）：证明决策价值——临床效用、监管路径、支付依据，才进入「**临床肿瘤数字孪生**」。我们**只在系统达到持续更新、患者特异性的决策阶段才使用「数字孪生」一词**，这是对科学的克制，也是对投资人的诚实。

> 【待核】原 BP 把 Level 1/2/3 写成「虚拟类器官 / 虚拟组织引擎 / 临床肿瘤数字孪生」，与科学家的定义不同。本版已改用科学家的三级定义；「虚拟组织引擎」「临床肿瘤数字孪生」保留为 Level 3 之后的产品化延伸，请科学家确认。

## 2.7 首个适应症：由流程匹配度决定，而非只看患病规模

| 标准 | 要求 |
|---|---|
| 可获得样本 | 连续组织与液体活检在临床和伦理上均可实施 |
| 类器官可靠 | 建库成功率、周期与检测重复性达到运营阈值 |
| 决策窗口适配 | 结果可在治疗方案选择或预设换药节点之前交付 |
| 结局可评分 | 治疗与随访能形成清晰的响应、耐药与进展终点 |

**优先候选：复发性脑肿瘤**——术后组织与脑脊液可连续获取；IPTO 已有前瞻研究基础；换药节点明确，PFS / OS 可评分。初始重点：评估一至两个复发性实体瘤项目，与临床中心和清晰的治疗路径结合。

> 【待核】科学家文档明确：上述为运营要求，**不表示任何特定瘤种已通过筛选**。正文宜写「优先候选、先完成可行性筛选」。

# 第三部分　做成之后：价值创造与投资回报

## 3.1 社会价值

- **让耐药与复发「提前被看见」**：从「治疗失败后才发现」变为「事前预测演化趋势」（例如模型提前提示干性↑、脂质代谢↑、治疗抵抗↑）。
- **让治疗决策有患者特异性证据**：在换药等决策窗口期输出针对这位患者的预测，并随临床结局持续校准——为精准肿瘤诊疗增加一层**功能证据**。
- **缩短试错、降低失败代价**：在临床结局显现前，先在虚拟空间完成药效推演，减少把资源投向最终无效的候选药物。
- **留下可复用的科学资产**：患者–PDO 纵向配对数据与可验证的因果生物模型，向跨疾病、多尺度延伸。

【待补充】可量化指标：目标瘤种年新发 / 复发患者数、可减少的无效治疗比例、可缩短的研发周期。

## 3.3 技术优势如何变成商业价值（把第二部分和第三部分连起来）

```
纵向配对数据 ──→ 模型更准 ──→ 客户项目交付更快、更可信
      ↑                                      │
      └──── 每个项目沉淀新的配对数据 ←────────┘
```

- **对客户**：为什么不自己建？核心壁垒（配对队列、培养偏差校正、跨项目模型复用）需要病例与时间，客户自建**门槛高、周期长**。
- **对我们**：数据越厚，**边际交付成本越低、毛利逐步提升**；项目交付与模型迭代在同一条生产链路，**服务收入与模型资产同步沉淀**。
- **对平台**：所有项目共用统一数据标准与模型架构，**平台效应自首批数据开始形成**。

# 结语：请记住这三句话

1. **为什么做**：耐药与复发总是后知后觉，而行业缺的是能做事前预测的真实配对纵向数据。
2. **为什么能成**：我们用同一位患者的**两条时间轨迹互相校准**，并用**前瞻评分**证明预测——这套配对数据与验证链路，别人无法靠算法追上。
3. **做成值多少**：每一个项目都让数据更厚、模型更准、成本更低；从研究合作走到临床决策支持，**证据走到哪里，收入就走到哪里**。
