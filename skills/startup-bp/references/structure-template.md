# BP 骨架模板（三段式）

括号里是每一节要回答的问题。示例取自 `docs/AIVC_BP_v5.md`。

---

## 封面
- 项目名称（中文 2 字 + 英文 1 词）——例：知微 Chronoid
- 使命 slogan（≤ 20 字）——例：让每一次治疗，先在患者自己的类器官上预演
- 产品名｜价值主张——例：AIVC 虚拟类器官｜让复发与耐药，在发生之前被看见
- 一行产品说明
- 本轮融资金额｜覆盖周期｜日期
- 名称说明框（含义、层级、待检索事项；选定后删除）

## 0. 一页纸摘要
| 三个问题 | 一句话回答 |
|---|---|
| ① 为什么要做？ | 需求有多痛 + 现有方案缺什么 |
| ② 为什么能成？ | 核心机制 + 几道别人没有的壁垒 |
| ③ 做成值多少？ | 对用户的价值 + 收入路径 + 复利逻辑 |

技术优势的三种说法：**一句话 / 一个公式 / 一个比喻**。

---

# 第一部分　为什么要做：市场需求与现有缺口
1.1 行业需求（现状代价有多大？——数字 + 出处）
1.2 用户 / 临床需求（谁在什么节点缺什么证据？——列 2–4 个具体缺口）
1.3 时机（为什么是现在？——哪些技术 / 政策条件刚刚成熟）
1.4 核心缺口（行业缺的到底是什么？——只讲缺口，不点名竞品、不预告方案；竞品放 2.8，第二部分开头承接）
> 小结：一句话

# 第二部分　为什么我们能做成：技术优势与护城河
2.1 核心思想（一张机制图）
2.2 技术如何实现（分步，每步解决一个问题）
2.3 数据飞轮：为什么越用越准（闭环 = 飞轮的一圈；数据分层；运行原则——全文只在这里完整展开）
2.4 护城河（壁垒表：是什么 / 为什么难复制 / 飞轮如何加深它）
2.5 如何证明（核心科学问题 + 示意（须标注为假设）+ 分级验证与阶段闸门）
2.6 首个场景 / 适应症（选择标准 + 优先候选，不夸大）
2.7 团队（按飞轮环节 / 价值链排列：角色 × 背景）
2.8 竞争格局（路线 / 融资估值 / 差异点；结论换一种说法再讲核心优势）
2.9 优势速记卡（他们 vs 我们，按角度对比）
> 小结：一句话

# 第三部分　做成之后：价值创造与投资回报
3.1 社会价值（可量化指标【待补充】）
3.2 商业价值与盈利模式（分阶段收入路径；客户各得什么；为什么客户不自建；为什么毛利会提高——引用 2.3 飞轮，不重复展开）
3.3 本轮融资与里程碑（金额、周期、用途占比与金额、里程碑 ↔ 验证层级、验收指标）
3.4 投资回报（TAM/SAM/SOM、收入预测、单位经济、估值与出让比例、退出路径、里程碑 → 估值跃升、参照案例）
3.5 主要风险与应对（见 investor-checklist）
> 小结：一句话

---

# 结语：请记住这三句话
1. 为什么做
2. 为什么能成
3. 做成值多少
最后一句与封面主标题呼应。
