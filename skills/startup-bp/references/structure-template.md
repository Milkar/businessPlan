# BP 骨架模板（三段式）

括号里是每一节要回答的问题。示例取自 `docs/AIVC_BP_v3.md`。

---

## 封面
- 主标题（价值 / 结果，≤ 20 字）——例：让复发与耐药，在发生之前被看见
- 副标题（项目名 + 用什么 + 做出什么）
- 本轮融资金额｜覆盖周期｜日期
- 备选主标题 ×3（价值导向 / 形象比喻 / 技术壁垒）

## 0. 一页纸摘要
| 三个问题 | 一句话回答 |
|---|---|
| ① 为什么要做？ | 需求有多痛 + 现有方案缺什么 |
| ② 为什么能成？ | 核心机制 + 几道别人没有的壁垒 |
| ③ 做成值多少？ | 对用户的价值 + 收入路径 + 复利逻辑 |

技术优势的三种说法：**一句话 / 一个公式 / 一个比喻**。

---

# 第一部分　为什么要做：市场需求与现有缺口
1.1 行业需求（现状代价有多大？——数字 + 出处）
1.2 用户 / 临床需求（谁在什么节点缺什么证据？——列 2–4 个具体缺口）
1.3 时机（为什么是现在？——哪些技术 / 政策条件刚刚成熟）
1.4 核心缺口（行业浪潮缺的到底是什么？——它就是我们的入口）
> 小结：一句话

# 第二部分　为什么我们能做成：护城河与技术优势
2.1 核心思想（一张机制图）
2.2 核心科学 / 产品问题与验证方式（示意须标注为假设）
2.3 技术如何实现（分步，每步解决一个问题）
2.4 护城河（壁垒表：是什么 / 为什么难复制；壁垒之间如何互相加固）
2.5 闭环运行（产品如何持续产生数据与改进；原则）
2.6 如何证明（分级验证 + 每级通过标准 = 阶段闸门）
2.7 首个场景 / 适应症（选择标准 + 优先候选，不夸大）
2.8 团队（角色 × 背景 × 职责；团队如何覆盖完整链路）
2.9 竞争格局（路线 / 融资估值 / 差异点；结论换一种说法再讲核心优势）
2.10 优势速记卡（按角度对比）
> 小结：一句话

# 第三部分　做成之后：价值创造与投资回报
3.1 社会价值（可量化指标【待补充】）
3.2 商业价值与盈利模式（分阶段：证据到哪一步，收入模式走到哪一步；合作伙伴各得什么）
3.3 技术优势如何变成商业价值（转化链 / 飞轮）
3.4 本轮融资与资金使用（金额、周期、用途占比与金额、里程碑、验收指标）
3.5 投资回报（TAM/SAM/SOM、收入预测、单位经济、估值与出让比例、退出路径、里程碑 → 估值跃升、参照案例）
3.6 主要风险与应对（见 investor-checklist）
> 小结：一句话

---

# 结语：请记住这三句话
1. 为什么做
2. 为什么能成
3. 做成值多少
最后一句与封面主标题呼应。
