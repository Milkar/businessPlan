# 投资人视角检查清单

成稿前逐项检查。✅ = 已有且有出处；⚠️ = 有但需核实或补充；❌ = 缺失，需放「待补充」框架。
**缺失项只搭框架、列口径，不编数字。**

## A. 通用（任何 VC 都会问）

| # | 项目 | 投资人想看到什么 |
|---|---|---|
| A1 | 一句话定位 | 做什么、给谁、解决什么，10 秒能复述 |
| A2 | 市场规模 | TAM / SAM / SOM，自下而上测算（客户数 × 单价），每个数字有出处和年份 |
| A3 | 为什么是现在 | 技术 / 政策 / 成本拐点 |
| A4 | 产品与进展 | 已做出什么（数据、样本量、原型、发表），和计划做什么分开写 |
| A5 | 牵引力 | 意向客户、LOI、合作协议、付费试点；没有就写获取路径 |
| A6 | 商业模式 | 谁付钱、为什么付、付多少、多久付一次 |
| A7 | 单位经济 | 单项目 / 单样本成本、毛利率、规模化后的变化 |
| A8 | 竞争 | 直接 / 间接竞品、替代方案（包括「客户自己做」）、差异点 |
| A9 | 团队 | 关键岗位是否齐全；全职 / 兼职；股权结构；缺口与招聘计划 |
| A10 | 融资 | 金额、周期、用途占比、里程碑（与资金逐项对应）、下一轮触发条件 |
| A11 | 估值与条款 | 投前估值、出让比例、期权池 |
| A12 | 财务预测 | 3–5 年收入 / 成本 / 现金流；关键假设单列 |
| A13 | 退出 | 并购方类型与可比交易、IPO 板块 |
| A14 | 风险 | 主要风险 + 对应缓释措施（主动写出来比被问出来更加分） |

## B. 生物医药 / AI4S / 医疗数据项目的附加项

| # | 项目 | 说明 |
|---|---|---|
| B1 | 人类遗传资源合规 | 中国：涉及患者样本 / 组学数据的采集、保藏、国际合作、数据出境需按《人类遗传资源管理条例》审批或备案；有外方参与时尤其关键 |
| B2 | 伦理与知情同意 | 合作医院伦理审批、知情同意覆盖纵向随访与数据二次使用 |
| B3 | 数据安全与出境 | 《个人信息保护法》《数据安全法》下的健康数据处理与跨境传输方案 |
| B4 | 监管路径 | 研究服务 → LDT / 医疗器械软件（NMPA 三类 / FDA）的路径与时间表；哪一阶段的收入不依赖注册证 |
| B5 | 临床验证设计 | 主要终点、样本量估算、对照（相对现有临床 / 影像 / 分子基线的增量价值）、预注册 |
| B6 | 知识产权 | 专利申请（方法、数据处理、模型）、与原单位（高校 / 研究所）的 IP 归属与许可 |
| B7 | 样本与数据来源 | 合作中心名单、协议状态、每月可入组病例数、建模成功率 |
| B8 | 关键人员投入 | 科学家是否全职、与原机构的雇佣 / 兼职安排 |
| B9 | 支付方 | 研究阶段谁付费（药企 / CRO）；临床阶段谁付费（医院 / 医保 / 患者自费） |

## C. 呈现质量

- 每个数字有可点开的来源链接或明确出处；口径（年份、币种、地区）一致。
- 同一数字全文一致（融资额、周期、占比加总 = 100%、金额加总 = 融资额）。
- 每页 / 每节一个结论性标题，而不是「市场分析」这类主题词。
- 示意 / 假设 / 计划 与 已完成的成果在措辞上明确区分。
- 路演版控制在 12–18 页；详细版可另附技术附录。
