## 二、生效规则
- **文件**：以 `AIVC_BP_v13.md` 为最新版，在 Markdown 上继续改；新版另存为 v4、v5…
- **结构**：一页纸摘要 → 第一步 为什么要做（1.1 行业代价 / 1.2 临床缺口 / 1.3 为什么是现在）→ 第二步 为什么我们能做成（2.1 核心缺口 = 技术壁垒的起点，2.2–2.10 技术、飞轮、护城河、验证、适应症、团队、竞争、速记卡）→ 第三步 做成之后 → 结语。
- **团队标题**：「团队：科学 × 数据 × 模型 × 运营，核心能力实现自持闭环」。
- **PPT 版式**：必须沿用用户提供的模板 `slides/template/AIVC_BP_template_2026-09.pptx`（深蓝封面 + 圆环装饰、目录四宫格、大号章节数字页、正文页标题 + 细线 + Source 页脚），只替换文字，不改版式、配色、字体与图形；模板页数不够时先问用户用哪一页套。
- **PPT 进度**（8 页，`slides/Vitoma_BP_part1_team.pptx`）：封面 → 目录（三栏：01 需求与时机 / 02 技术壁垒与团队 / 03 商业价值与回报）→ 01 章节页 → 痛点（药物研发）→ 临床痛点（沿用药物研发痛点版式：静态 证据 / 滞后 反馈 / 割裂 三个大字 + 流程条 + 深色「方向」框，无配图）→ 为什么是现在（右侧面板为第一部分小结）→ 02 章节页 → 团队（四张照片占位 + 姓名 + 职位 + bullet，不再用段落 + 表格）。第二、三部分其余页面待卓悦博士、田伟利博士补充科学技术内容。
- **数据飞轮**：只在第二步 2.4 出现一次，作为解释「模型为什么越用越准」的工具，七步闭环就是飞轮的一圈；护城河、团队、商业模式只引用它，不再单列飞轮章节。
- **封面**（v8）：
  - 公司名称：**Vitoma**（中文名暂不上封面：「维拓」与深圳「韦拓生物」同音，待律师评估，见 `docs/naming-check-vitoma.md`）
  - 名称拆写（放在 Vitoma 正下方）：Virtual Intelligence Twin & Organism Modeling Architecture（团队选定；路演时把「Twin」解释为长期愿景）
  - 使命 slogan（突出科学底层原理）：患者与类器官双轨校准，预见肿瘤的下一步
  - 英文 slogan：Patient and organoid, calibrated in parallel — to foresee the tumor's next move.
  - 产品｜价值主张：AIVC 虚拟类器官｜让复发与耐药，在发生之前被看见
  - 产品说明：用患者自己的肿瘤类器官，训练出能预测其治疗响应与复发的虚拟模型
  - 融资：5000 万元人民币（覆盖 12 个月）
- **团队**：四人同属创始团队，职务只写 C 级头衔——卓悦博士 = CEO（Verqura 实验室管理系统创始人）；田伟利博士 = CSO；王中杰博士 = CTO；兰晓静 = COO。不写「创始人 / 联合创始人」。团队页排版（PPT）：最常见的初创团队页——四张照片、姓名、职位，下方 bullet 简述经历，不用表格。王中杰博士为慕尼黑工业大学 / 亥姆霍兹中心生物信息学博士，不写博后经历；田伟利博士为慕尼黑大学 / 亥姆霍兹中心神经生物学博士。成员介绍以简历为准（`docs/` 外的上传简历，2026-10）：每人一句亮点标签 + 5 条 bullet，粗体开头突出最亮的点。不使用对卓悦博士的性别代词。
- **预算**：Plan A 自下而上测算约 3936 万元；约 1064 万元（21%）为 Plan B 准备金，独立账户、按触发条件经董事会批准动用；融资期内不计收入。
- **里程碑**：只保留第 6、12 个月；原第 18、24 个月的目标列为「12 个月之后（下一轮融资目标）」。
- **技术优势与价值**：全文反复出现，每次换一种说法（一句话、公式、比喻、对比表、速记卡、结语三句话），不得重复同一段话。
- **科学内容**：以科学家文档为准——双轨迹校准、三级验证（Level 1/2/3 用科学家定义）、四道壁垒、七步闭环。不夸大「数字孪生」，不宣称已选定瘤种。
- **数字**：不编造。投资回报在团队提供数字前保持「待补充」框架。
