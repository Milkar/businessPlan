# AIVC 虚拟类器官项目：当前生效的规则

来源：本地对话「创业项目BP重构」的总结（2026-10）。最新稿：`docs/AIVC_BP_v7.md`（旧版本保留作对照）。

## 一、历次修改要求（按时间顺序）
1. PPT 版 BP 转成 Markdown 继续修改（节省流量）。
2. 重构为三件事：为什么做（市场需求与缺口）→ 为什么能成（护城河 / 技术优势）→ 做成的价值与投资回报（社会价值、商业价值、盈利模式、投资回报率）。
3. 封面标题太长太复杂，要缩短。
4. 融资周期：5000 万覆盖 **12 个月**，不是 24 个月。
5. 按科学家两份文档（HTML 商业计划、虚拟类器官 PPT）继续优化：突出技术优势和价值，并以不同方式重复。
6. 标题页继续改：简洁、有说服力。
7. 项目缺少有力、有意的名字和一句讲清使命的 slogan，要放在封面上（→ v4）。
8. 按三步走结构重构；数据飞轮作为解释技术原理的辅助工具融进技术部分，不单独列出（→ v5）。
9. 1.4 只讲缺口：竞品挪到 2.8，2.1 开头承接（→ v6）。
10. 商业价值部分按 5000 万做成本与预算模拟，为 Plan B 留存准备金（→ v7，模型 `docs/AIVC_budget_model.xlsx`）。

## 二、生效规则
- **文件**：以 `AIVC_BP_v7.md` 为最新版，在 Markdown 上继续改；新版另存为 v4、v5…
- **结构**：一页纸摘要 → 第一步 为什么要做 → 第二步 为什么我们能做成 → 第三步 做成之后（价值与回报）→ 结语。
- **数据飞轮**：只在第二步 2.3 出现一次，作为解释「模型为什么越用越准」的工具，七步闭环就是飞轮的一圈；护城河、团队、商业模式只引用它，不再单列飞轮章节。
- **封面**（v4）：
  - 项目名称：知微 Chronoid【待定，备选见 `docs/naming.md`】
  - 使命 slogan：让每一次治疗，先在患者自己的类器官上预演
  - 产品｜价值主张：AIVC 虚拟类器官｜让复发与耐药，在发生之前被看见
  - 产品说明：用患者自己的肿瘤类器官，训练出能预测其治疗响应与复发的虚拟模型
  - 融资：5000 万元人民币（覆盖 12 个月）
- **预算**：Plan A 自下而上测算约 3936 万元；约 1064 万元（21%）为 Plan B 准备金，独立账户、按触发条件经董事会批准动用；融资期内不计收入。
- **里程碑**：只保留第 6、12 个月；原第 18、24 个月的目标列为「12 个月之后（下一轮融资目标）」。
- **技术优势与价值**：全文反复出现，每次换一种说法（一句话、公式、比喻、对比表、速记卡、结语三句话），不得重复同一段话。
- **科学内容**：以科学家文档为准——双轨迹校准、三级验证（Level 1/2/3 用科学家定义）、四道壁垒、七步闭环。不夸大「数字孪生」，不宣称已选定瘤种。
- **数字**：不编造。投资回报在团队提供数字前保持「待补充」框架。
